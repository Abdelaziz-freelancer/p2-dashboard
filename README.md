# لوحة تحكم الموقع (المشروع رقم 2)

مشروع Vercel منفصل عن الموقع. بتدخل منه: الحجوزات، المواعيد، البريفات، وإعدادات الموقع (سرعة الشرايط وأنيميشن لوجو ميتا).

## الإعداد (مرة واحدة)
1. **Supabase:** اعمل Project جديد، وفي SQL Editor شغّل ملف `supabase-schema.sql` (الموجود في زيب الموقع).
2. **من Project Settings > API** هتحتاج 3 حاجات:
   - Project URL
   - anon public key: بتتحط في `config.js` بتاع الموقع بس
   - service_role key: سرية جداً، بتتحط هنا في Vercel بس، وما تتحطش في الموقع أبداً
3. ارفع محتويات الفولدر ده (مش الفولدر نفسه) على ريبو GitHub جديد.
4. في Vercel: Add New > Project > اختار الريبو > Deploy.
5. في Vercel: Settings > Environment Variables، وضيف التلاتة دول:
   - `ADMIN_PASSWORD` = كلمة السر اللي هتدخل بيها الداشبورد (اكتبها بنفسك هنا، هي مش مكتوبة في الكود)
   - `SUPABASE_URL` = الـ Project URL
   - `SUPABASE_SERVICE_ROLE_KEY` = الـ service_role key
6. Deployments > آخر Deployment > Redeploy عشان المتغيرات تشتغل.
7. افتح رابط الداشبورد، ادخل بالباسورد، ومن تاب "المواعيد" ضيف مواعيدك. بعدها العملاء يقدروا يحجزوا من الموقع.

## ملاحظات
- كل الأوقات بتوقيت القاهرة.
- حذف حجز بيرجّع الميعاد متاح تاني.
- الداشبورد مخفية عن محركات البحث (noindex)، بس خلي رابطها عندك.
- تاب "ميتا وتيك توك" لسه "قريباً".
