# لوحة تحكم الموقع (النسخة 2)

مشروع Vercel منفصل عن الموقع.

## الإعداد (مرة واحدة)
1. ارفع محتويات الفولدر ده (مش الفولدر نفسه) على ريبو GitHub جديد، وفي Vercel اعمله Import وDeploy.
2. في Vercel: Settings > Environment Variables، وضيف التلاتة دول:
   - `ADMIN_PASSWORD` = كلمة السر الرئيسية بتاعتك (اكتبها بنفسك، مش مكتوبة في أي ملف)
   - `SUPABASE_URL` = `https://vxvqfybkeavvvzrlhqwh.supabase.co`
   - `SUPABASE_SERVICE_ROLE_KEY` = المفتاح السري من Supabase (Project Settings > API Keys). سري جداً، متحطوش في الموقع.
3. Deployments > آخر Deployment > Redeploy.

## الدخول
- **أنت (صاحب الموقع):** سيب اسم المستخدم فاضي واكتب كلمة السر الرئيسية.
- **المشرفين:** من تاب "المشرفين" بتضيف مشرف باسم مستخدم وكلمة سر (8 حروف على الأقل) وتحدد صلاحياته (عرض أو تعديل) لكل قسم.

## التابات
الحجوزات، المواعيد، البريفات، محتوى الموقع (النصوص، الخدمات، البراندات، الحملات، الشوكيس، الآراء)، أسئلة البريف، الإعدادات (الصور، الخطوط، اللغة والإضاءة الافتراضية، سرعة الحركة، واتساب والسوشيال)، الإشعارات (قريباً)، المشرفين، ميتا وتيك توك (قريباً).
